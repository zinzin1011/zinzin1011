# 회의 녹음 시작

1. 사용자가 회의 종류를 말했으면 그 이름을 쓰고(예: "정기회의 시작" → `정기회의`), 없으면 `회의`.
2. 실행:
   ```bash
   python -m meeting_bot record start --name <이름>
   ```
3. 결과를 한두 줄로 알린다: 녹음 파일 경로, 그리고 "끝나면 '회의 끝'이라고 말해 주세요".
   - 회의실에서는 노트북을 테이블 가운데 두고, 시작할 때 한 명씩 "○○○입니다" 하고 한마디씩 하면
     화자 이름 매칭이 정확해진다는 것도 처음 한 번만 짧게 안내한다.
4. 실패하면(마이크 권한, 장치 번호) 출력된 안내를 그대로 전하고,
   장치가 문제면 `python -m meeting_bot record devices` 결과를 보여 주며 `.env` 의 `RECORD_DEVICE` 를 고르게 돕는다.
